# Unified Console — v0 Brand Spec

- Product role: local API account and routing console.
- Visual anchor: Sub2API resource management, New API data density, rycarl.cn soft glass surfaces.
- Logo: no official logo asset exists. Use the plain `Unified` wordmark; do not invent a symbol.
- Product imagery: none required for this utility interface.
- Primary: `#368dcc`; accent tint: `#e4f2fc`.
- Canvas: `#eef3f7`; ink: `#17212b`; muted: `#6f7d89`.
- Type: local system UI stack with tabular numerals for operational data.
- Spacing: 4px base; 8 / 12 / 16 / 24 / 32.
- Radius: shell 18px; cards 14px; controls 10px.
- Elevation: borders for normal separation; one soft shadow for floating shells.
- Motion: 160ms ease-out, limited to hover, navigation, and overlays.
